# Country Explorer — Финальный проект

## Описание
Персонализированное offline-first приложение для исследования стран мира на базе REST Countries API. Позволяет искать страны, добавлять в избранное, вести заметки, отслеживать историю просмотров и настраивать приложение под себя.

## Что добавлено в финальной работе

### Новые экраны
- **Настройки** — тёмная тема, офлайн-предзагрузка, автоочистка истории
- **История просмотров** — список недавно просмотренных стран с датами
- **Персональные заметки** — создание, редактирование, удаление заметок к странам

### Новые сущности Room
- `HistoryEntity` — история просмотров (id, countryId, countryName, timestamp)
- `NoteEntity` — заметки пользователя (countryId, text, lastEdited)
- `CountryEntity` — кэш стран для офлайн-доступа (id, name, capital, region, population, area)

### Технологии
- **DataStore** — настройки приложения
- **WorkManager** — фоновая синхронизация кэша и очистка истории
- **Flow** — композиция 4 источников (searchQuery, tagFilter, cachedCountries, refreshTrigger)

## Три пользовательских сценария

### Сценарий A: Заметки к стране (существенный)
1. Открыть детальную информацию о стране
2. Нажать «Добавить заметку»
3. Ввести текст → сохранить
4. Заметка отображается на экране деталей с датой изменения
5. Редактировать или удалить заметку
6. Все заметки доступны в разделе «Мои заметки»

### Сценарий B: История просмотров (существенный)
1. Перейти на любую страну → запись автоматически добавляется в историю
2. Открыть раздел «История» → список с датами просмотров
3. Удалить отдельную запись или очистить всю историю
4. WorkManager автоматически удаляет записи старше N дней

### Сценарий C: Офлайн-доступ и настройки (средний)
1. При первом запуске с интернетом все страны кэшируются в Room
2. В режиме «В самолёте» список стран и детали работают из кэша
3. Поиск работает на кэшированных данных
4. Настройки (тема, автоочистка) применяются мгновенно

## Offline-first

### Как устроен кэш
- Все страны сохраняются в Room (`cached_countries`) при первом успешном запросе
- `CountryDao` предоставляет `Flow<List<CountryEntity>>` для реактивного доступа
- UI получает данные через `getCachedCountriesFlow()`

### Стратегия работы без сети
1. UI сначала показывает данные из Room (мгновенный ответ)
2. Параллельно проверяется доступность сети (`NetworkUtils`)
3. При отсутствии сети — данные из кэша с плашкой «Автономный режим»
4. При наличии сети — данные обновляются из API и сохраняются в кэш

### Что работает без интернета
- Список всех стран
- Поиск по названию
- Детальная информация о стране
- Избранное
- История просмотров
- Заметки

## Фоновая обработка (WorkManager)

### CacheRefreshWorker
- **Задача:** обновление кэша стран из API
- **Периодичность:** раз в 24 часа
- **Условия:** требуется интернет-соединение
- **Назначение:** поддержание актуальности данных для офлайн-доступа

### HistoryCleanupWorker
- **Задача:** удаление устаревших записей истории
- **Периодичность:** раз в 24 часа
- **Логика:** удаляет записи старше N дней (настраивается в DataStore)
- **Назначение:** автоматическая очистка, экономия места
